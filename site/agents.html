AI agents

Claude, or any assistant that speaks the Model Context Protocol (MCP), can use Communal for you: find and download files, share folders, change who can see them, manage connections and subscriptions, and show you the result in the app.

With the app

  1. Open Settings › AI agents and turn on Allow control from the CLI and AI agents. It takes effect straight away; there’s no need to restart.
  2. Copy the command shown there and run it once in a terminal to add Communal to Claude Code. For Claude Desktop or another MCP client, copy the settings block into its MCP servers configuration instead.

The assistant then talks to the app that’s already open. When it opens a screen for you, the app’s window comes forward and goes there.

Only programs running as you on the same computer can connect, and only while the setting is on.

On a server

With the headless client, use its own command:

claude mcp add communal -- communal mcp

It finds the running communal daemon (or the open app) by itself, and keeps working when either restarts. Set COMMUNAL_DATA if the daemon uses a different data folder.

What an assistant can do

Area Tools
Overview get_status, list_hubs, self_check
Finding files search_files, list_library, browse_folder, preview_text
Downloads download_file, list_transfers, cancel_transfer, get_activity
Sharing list_shares, share_folder, stop_sharing, set_share_hubs, get_access_rules, set_access
People list_connections, find_people, request_connection, accept_connection, remove_connection, list_groups, save_group, delete_group
Subscriptions list_subscriptions, subscribe_folder, update_subscription, unsubscribe
Hubs and settings join_hub, leave_hub, list_devices, get_network, check_network, get_settings, set_upload_limits
The app window show_in_app

Tools that change something are marked as such, so your assistant asks before using them. Opening a folder to other people (set_access, share_folder) deserves a careful look.

What it can’t do

Some things always need you: an assistant can’t see or save your recovery key, add, approve or remove your computers, or mark a person as verified (that means comparing a code with them yourself).

Things to ask

  • “Find the lake trip photos Maya shared and download them to my Pictures folder.”
  • “Share my Music folder with everyone on the family hub.”
  • “Who downloaded files from me this week?”
  • “Why is my download from Sam stuck?”
  • “Show me Maya’s Photos folder in the app.”
